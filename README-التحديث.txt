مؤسسة بصمتك خضراء — تحديث حسابات الهيكل الإداري والثيمات
======================================================

الملفات:
- index.html: الصفحة الرئيسية كما هي.
- admin.html: لوحة الإدارة بعد إضافة حسابات المناصب والثيمات.
- assets/: الصور الأصلية.

الدخول إلى لوحة الإدارة:
- اسم المستخدم: admin
- كلمة المرور الافتراضية: 123456
إذا سبق تغيير كلمة مرور المدير في نفس المتصفح، استخدم كلمة المرور الحالية المحفوظة هناك.

التحديثات:
1) إضافة اسم مستخدم إلى شاشة الدخول.
2) إضافة قسم "حسابات المناصب" للمدير الرئيسي.
3) إنشاء حساب لكل منصب موجود بالهيكل، مع اسم مستخدم وكلمة مرور.
4) تعيين صلاحيات منفصلة لكل حساب.
5) تفعيل/إيقاف/حذف الحسابات وتغيير كلمة مرور الحساب من نموذج التعديل.
6) إضافة 5 ثيمات جاهزة وثيم مخصص للألوان.
7) حفظ إعدادات الثيم بشكل منفصل لكل حساب داخل المتصفح.

مهم — حدود النسخة الحالية:
الموقع الحالي صفحات HTML ثابتة ولا يحتوي على خادم مصادقة أو قاعدة بيانات متصلة. لذلك الحسابات وكلمات المرور (المحفوظة كـ SHA-256 hash) والبيانات تظل في localStorage على نفس المتصفح والجهاز. هذا تنفيذ أولي للواجهة وتجربة الصلاحيات، وليس حماية إنتاجية: لا تستخدمه لتوزيع حسابات حقيقية أو بيانات حساسة، ولا يمكن للحسابات تسجيل الدخول من أجهزة أخرى أو مشاركة التحديثات بين أجهزة الفريق.
للتشغيل المؤسسي الحقيقي يجب ربط Firebase Authentication أو Supabase Auth، وتخزين الأدوار والصلاحيات في قاعدة البيانات، وفرضها بقواعد أمان خادمية (Firestore Security Rules أو RLS). لا تضع كلمات مرور أو مفاتيح خدمة سرية داخل HTML.
